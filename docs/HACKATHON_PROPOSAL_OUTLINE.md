## 頁面大綱架構（12 頁 16:9 簡報）

### P1. 封面與隊伍亮點
- **專案名稱**：Lexa-EdgeAgent
- **一句話核心**：在極限顯存受限與無網路環境下，透過非對稱記憶體排程實現 3.17x 推論加速的工業自主巡檢 Agent。
- **目標場景**：智慧製造／半導體與高階製造廠區邊緣無網自主運維。

### P2. 產業痛點與邊緣核心挑戰
- **痛點 1（無網/弱網隔離）**：晶圓廠與重工業嚴禁資料上雲，但邊緣工控機／Jetson 設備 VRAM 嚴重受限。
- **痛點 2（顯存溢位懸崖）**：大參數 Agent 遇顯存不足時，傳統框架全數退回 CPU 導致推論延遲暴增 3~4 倍（跌至 25 tokens/s）。
- **痛點 3（Agentic 閉環延遲）**：多步驟任務分解與工具調用時，因短板效應（Straggler）導致整體回應嚴重卡頓。

### P3. 解決方案：Lexa-EdgeAgent 雙層系統架構
- **上層（Agentic Orchestration Layer）**：自主任務拆解、多模態相機/PLC 工具調用、狀態反思與安全中斷。
- **下層（Asymmetric Compute Substrate）**：`Lexa-AsymCompute` Roofline 數學模型 + 三階層記憶體動態排程。

### P4. Agentic 核心機制 1：目標拆解與閉環執行
- 符合大會門檻：具備「異常檢測 $\to$ 本地診斷 $\to$ 邊緣派工」至少三段依賴關係的自主推進流程。
- 動態重試：當感測資料不完整或推論置信度不足時，主動調用邊緣感測器重新取樣。

### P5. Agentic 核心機制 2：工具調用與安全邊界
- **工具庫（Tools）**：Modbus/PLC 暫存器讀寫、視覺瑕疵比對微模型、歷史故障資料庫檢索。
- **權限控制（Guardrails）**：高風險停機操作強制提示人工授權，具備失敗復原機制與完整審計日誌。

### P6. 邊緣算力底座：非對稱記憶體排程數學模型
- **三階層平滑分流**：GPU 顯存（Hot Experts）+ 系統 RAM（Warm Experts）+ 本地 NVMe（Cold Experts）。
- **時序快取保留（Temporal Holdout Cache）**：針對工業工況的專家路由偏好預先排程，達到 **70.48% 快取命中率**。

### P7. NVIDIA 生態深度整合（直擊決賽評分標準）
- **模型選型**：採用 **NVIDIA Nemotron-Mini** 作為邊緣核心推理引擎。
- **硬體適配**：針對 **NVIDIA Jetson AGX Orin / Thor** 統一記憶體架構（UMA）與邊緣工控機進行底層頻寬對齊。
- **框架對接**：原生相容 NVIDIA NeMo 架構與 NeMo-Guardrails 安全護欄。

### P8. 實測數據驗證（實機測量非單純推估）
- **延遲降低**：從 CPU/RAM Baseline 39.57 ms 降至 **12.49 ms（延遲降低 68.4%）**。
- **吞吐量提升**：推論速度提升 **+216.8%（3.17 倍速）**。
- **異質管線加速**：相較於盲目 50/50 分配，異質交錯排程帶來 **13.37 倍速吞吐量突破**。

### P9. 實際落地展示情境（User Journey）
- **無網巡檢情境示範**：巡檢機器人進入無訊號機房 $\to$ 視覺捕捉儀表指針異常 $\to$ 本地 Agent 多步分析 $\to$ 自動開立維修單。

### P10. 商業價值與可行性評估
- **硬體成本節省**：利用 Lexa 排程，在平價 Jetson / 工控機上即可跑原本需高階工作站才能負載的模型，邊緣節點硬體成本降低 60%。
- **資料零外洩**：100% 離線本地推論，完全符合半導體與國防資安標準。

### P11. 隊伍組成與分工架構
- 跨領域 4~8 人編制：演算法工程師（Lexa 排程）、邊緣嵌入式工程師（Jetson/NeMo 部署）、工業軟體工程師（PLC/Modbus 介面）、產品架構師。

### P12. 願景與里程碑規劃
- **決賽前（10/02–10/21）**：完成 NeMo 實機對接與 Jetson Orin 現場部署。
- **現場黑客松（10/22–10/23）**：在 DGX Spark / Jetson 現場進行 10 分鐘即時無網閉環 Demo 發表。
