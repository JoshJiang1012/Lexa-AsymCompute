# Formula cheatsheet

```math
P_{d}=\eta_{d}^{P}P_{d}^{\mathrm{peak}},\qquad B_{d}=\eta_{d}^{B}B_{d}^{\mathrm{peak}}
```

```math
F_{d}=x_{d}F_{p}+F_{d}^{m},\quad Q_{d}=x_{d}Q_{p}+Q_{d}^{m},\quad R_{d}=x_{d}R_{p}+R_{d}^{m}
```

```math
R_{d}\le C_{d}
```

```math
T_{d}=\max(F_{d}/P_{d},Q_{d}/B_{d})+\ell_{d}+T_{d}^{\mathrm{transfer}}
```

```math
T_{\mathrm{parallel}}=\max_{d}T_{d}
```

```math
T_{\mathrm{total}}=T_{\mathrm{serial}}+T_{\mathrm{parallel}}+\tau_{\mathrm{sync}}
```

```math
\Theta=1/T_{\mathrm{total}}
```

```math
J(x)=\lambda_{T}T_{\mathrm{total}}+\lambda_{E}E_{\mathrm{total}}
```

```math
A(c)=1-\frac{(\sum c_{i})^{2}}{n\sum c_{i}^{2}}
```

```math
S=T_{b}/T_{o},\qquad R_{T}=1-T_{o}/T_{b}
```

```math
H_{\mathrm{prefetch}}\ge\lceil T_{\mathrm{load}}/\tau_{\mathrm{stage}}\rceil
```
